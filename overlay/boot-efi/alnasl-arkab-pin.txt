# ARKAB REMOTE PIN
#
# WHAT IT IS FOR
# Arkab's status page (http://<this box>:4050) is read-only for everyone except
# the box itself. With a PIN set, someone on another computer in the hall
# (a phone, a laptop) can unlock it and press the buttons: join a server,
# update, and so on. This box has no screen and no keyboard, so you set the
# PIN here, on a PC.
#
# HOW
# Type the PIN after "PIN=" below, save, put the card back in the box and boot.
#   - 4 to 64 characters. Digits only is fine (4 to 8 digits is plenty).
#     Letters and other characters are allowed too; keep to plain keyboard
#     characters.
#   - No spaces at the start or the end, and no quotes around it.
#   - To REMOVE the PIN again, write PIN=remove (in Dutch: PIN=verwijderen).
#     So "remove" itself cannot be your PIN. Nobody minds.
#
# WHAT HAPPENS
# At boot the box gives the PIN to Arkab and then EMPTIES the PIN= line again,
# so the PIN does not stay on the card. The file itself stays, so you can fill
# it in again later. The last line of this file says what became of it
# ("PIN set", or why it was refused). Changing or removing the PIN locks every
# browser that was unlocked before.
# Only a box whose role is Arkab reads this file; on any other role it is left
# alone.
#
# MIND THE NETWORK
# The page is plain HTTP, so the PIN crosses the hall's network in clear. It is
# a lock against people in the hall, not against the internet.
#
